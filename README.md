# BI-project
# Анализ кредитного риска и разработка дашборда

## Цель проекта
Разработка ETL-процесса и создание аналитической витрины данных для визуализации риск-метрик кредитного портфеля. 

## Инструменты
*   **Python (Pandas)** — предобработка и очистка данных (ETL).
*   **SQL (SQLite)** — написание сложных запросов, агрегация данных и создание аналитической витрины (View).
*   **DataLens** — разработка интерактивного дашборда.
*   **Инструменты**: Google Colab, DBeaver, DataLens.

## Этапы работы
1.  **ETL:** 
    *   Загружен датасет [Credit Risk Dataset](https://www.kaggle.com/datasets/laotse/credit-risk-dataset) (Kaggle).
    *   С помощью Python (Pandas) проведена очистка данных от пропусков и предобработка признаков.
    *   Очищенные данные загружены в реляционную базу данных SQLite.
2.  **Разработка витрины данных (SQL):**
    *   Написан SQL-скрипт для создания витрины `risk_mart`.
    *   **Использованы оконные функции:** 
        *   `SUM() OVER (ORDER BY ...)` для расчета накопленного объема портфеля.
        *   `RANK() OVER (PARTITION BY ...)` для ранжирования целей кредита по уровню дефолтности внутри каждого кредитного грейда.
3.  **Визуализация (DataLens):**
    *   Построен интерактивный дашборд для мониторинга рисков.
    *   Включены индикатор, график накопления портфеля, распределение по целям и уровням риска.

##  Результаты 
*   Выявлена прямая зависимость: уровень дефолтности растет от грейда A (~12%) к грейду G (~99%).
*   На долю самых рискованных грейдов (F и G) приходится минимальный объем денег, что говорит о консервативной кредитной политике.
*   Основной объем проблемных долгов сконцентрирован в таких целях, как Debt Consolidation и Medical.
